Connect production market data

Use your regular Kalshi account, not Kalshi Demo.

  1. Open Kalshi Account & security → API Keys.
  2. Choose Create Key, give it a name such as Money Tree Paper, and select Read permission. Read-only is recommended.
  3. Save the API key ID and download the private-key file when Kalshi shows it. Keep the original file safe; Kalshi only shows the private key once.
  4. Copy the key ID below, then upload the private-key file or paste its complete contents. Click Verify production Read connection.

Watch the status at the top of DEMO: the worker verifies the production feed before simulating orders. This engine never uses trading permissions and cannot place real orders.
