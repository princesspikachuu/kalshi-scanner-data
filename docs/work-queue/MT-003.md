## Processing bottleneck evidence

`shadow_pipeline_cost` from 06:38–06:42 shows approximately **17k–31k processed inputs per 30–36 second window**. Input types are dominated by orderbook deltas, typically **15k–32k per window**, versus around **1.5k–3k trades**. On multiple windows, combined simulated processing and durable commit time approaches the entire wall-clock interval. The work is often near saturation.

At 06:40:03, the pipeline recorded 28,802 handled inputs, 13.0 seconds simulation time and 16.7 seconds commit time for a roughly 35.7 second reporting window, with 18,521 buffered inputs. These costs are observed diagnostic aggregates, not per-trade execution costs.

The existing pipeline's `observations_total` is **0 for Favorites** even as `favorite_paper_entry` and `FAVORITE_ENTRY_COHORT` events occur. That generic metric is not implemented for the Favorites trial model; **do not report 0 as a genuine observation count**.

The `favorites_statistics` portfolio had a virtual cash balance of $1,000 and zero open contracts in sampled health windows. That is not itself a bug: its evidence gating may correctly be waiting for enough validated outcomes.

## Working conclusions

1. MT-001 is producing repeated paper orders and entry fill cohorts. The growth in attempted observations is real, but the number of *new statistically independent settlement outcomes* remains unmeasured.
2. Near-saturated orderbook-delta processing and stale-book rejections are the first throughput/data-quality bottleneck to investigate. Preserve strict causal order, sequenced snapshots, and stale-data exclusions; never manufacture valid observations from rejected inputs.
3. Reporting must distinguish **candidate opportunities → order attempts → actual filled cohorts → verified settled unique events → evidence-eligible samples**. Raw order count is not a sufficient measure of learning speed.
4. Keep paused strategies paused and keep the trading path paper-only; don't increase subscriptions until latency and rejection behavior are controlled.
