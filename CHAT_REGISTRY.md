# Money Tree — Numbered Chat Registry

**Project-wide user requirement (2026-11-21, Pacific): EVERY Money Tree development chat must number itself.** This applies to new chats and existing development chats when they next continue. This registry uses a sequence independent of GitHub PR numbers and MT-### queue task IDs.

## Startup and handoff rules

1. Read `WORK_QUEUE.md` and this registry from `main` **before** claiming or continuing development work.
2. If this conversation is not already in the registry, reserve the **next unused sequential integer** with a short descriptive topic. Update this file on `main`; re-read if another chat edited it first and select the new next integer. **Never reuse a number**, even if the topic changes or a chat finishes.
3. Begin the chat's first substantive status with the label **Money Tree — Chat ##: [short topic]**. Use the identical chat number in every handoff summary, related task update, and PR coordination note.
4. The user must rename the actual conversation in ChatGPT manually; the assistant can suggest the exact title but cannot rename the app's chat itself.
5. Do not confuse **Chat 01** with MT-001, PR #1, or numbered code tasks. A change in PR or task ownership does not require a new chat number within the same conversation.
6. Continue work only within the active regular High-Probability Favorites scope and existing queue ownership rules; numbering is coordination, not permission to take another chat's task.
7. For legacy chats already running when this instruction was written, reserve their own next unused number on their next reply. This registry cannot retroactively rename or assign a number to a chat without its participation.
